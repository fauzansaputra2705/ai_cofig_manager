## Ringkasan

Mengubah urutan tab Pi config supaya Models tampil pertama, menghapus tab Sessions dari halaman detail provider, dan menambah feedback UI untuk aksi tambah/hapus provider serta model.

## Konteks

- **Requirement:** Models jadi tab pertama, Settings kedua, Sessions dihapus, add action menampilkan toast, delete action menampilkan warning.
- **Acceptance Criteria:** Tab Pi berurutan Models → Settings → MCP, tab Sessions tidak muncul di detail provider, Add provider/Add model menampilkan toast, delete provider/model butuh konfirmasi dan memberi warning draft.

## Perubahan

| `templates/providers/detail.html` | UPDATE | Hapus tab Sessions dari tab detail provider non-Pi. |
